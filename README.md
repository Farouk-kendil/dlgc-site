# DLGC Business Website

A business website for DLGC that centralizes customer resources, documentation, downloads, training material and company contact information.

## Main sections

- ERP documentation
- Technical videos
- Downloads
- Barcode resources
- Server resources
- Printing-model resources
- Customer assistance access
- Company contact information

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive web design

## Repository structure

The current website snapshot is stored in the `dlgc66/` directory.

## Local use

Open the project through a local web server when working with the complete version that includes PHP pages.
